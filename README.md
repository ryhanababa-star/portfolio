# Portfolio – Ryhanatou BABA

Site statique, sans étape de build, déployé sur Vercel : https://ryhanatou-baba.vercel.app

- `index.html` : version française. `en.html` : version anglaise (servie sur `/en` grâce à `vercel.json`).
- Toute modification de contenu se fait **dans les deux fichiers**.
- Les projets sont dans le bloc `<script type="application/json" id="projets-data">` de chaque page ; images à la racine.
- Formulaire de contact : Web3Forms. Remplacer `VOTRE_CLE_WEB3FORMS` par la clé reçue par e-mail, dans les deux pages.
